**HOTEL APP**

This is a Hotel Management System I built using Java, JDBC and MySQL while learning. It allows managers and users to perform different types of hotel-related functions.
Users can book rooms, book party halls and also book meeting halls, and also take swimming pass, playzone pass and gym pass. The application stores booking and billing details in MySQL database and uses a scheduler to automatically expire bookings when their time is over.
I used JDBC with the DAO pattern to handle database operations and practiced concepts like OOP, SQL, CRUD operations, PreparedStatement, LocalDateTime and scheduling while building this project.
This is mainly a learning project, and I plan to improve it as I learn more.
